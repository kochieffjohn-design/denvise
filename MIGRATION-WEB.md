# Миграция Denvise в веб (PWA)

План зафиксирован 29.09.2026 по итогам обсуждения. Цель — запуститься как платный веб-сервис вместо публикации в App Store / Google Play, сохранив возможность вернуться в сторы позже.

## 1. Клиент

- **Та же кодовая база**: Expo Router + React Native Web. `react-native-web` и `react-dom` уже в зависимостях, экраны написаны на обычных RN-примитивах — переписывать не нужно.
- **Должно выглядеть как приложение** — без этого не запускаемся. Ориентир — keenee.app. Критерии готовности:
  1. Устанавливается как PWA: манифест, иконки, сплэш, режим standalone без адресной строки.
  2. Нижние табы, учтены safe-area/«чёлка»; все `Platform.OS === 'ios' ? 54 : 44` заменены на safe-area.
  3. Нет зума при фокусе в поле (шрифт полей ≥ 16px), нет «резинки» страницы.
  4. Нет выделения текста на UI, мгновенный визуальный отклик на нажатие.
  5. Анимации переходов, скелетоны вместо спиннеров, обработка отсутствия сети.
  6. 60 fps при прокрутке.
  7. На десктопе — приложение по центру шириной ~480px на брендовом фоне.
- Приёмка на реальных устройствах: iPhone (Safari и установленное PWA) и Android (Chrome).
- Офлайн на запуске: оболочка приложения и бесплатный контент из бандла.
- Порядок первого входа: онбординг → вход → приложение.

## 2. Архитектура бэкенда

Разделение продиктовано 152-ФЗ: первичный сбор и хранение персональных данных — на территории РФ.

```
Клиент (PWA, denvise.ru)
   │  все запросы
   ▼
Ядро — Yandex Cloud (РФ)
   • Postgres: пользователи, подписки, прогресс, попытки, банк аккредитации
   • авторизация, подписки, вебхуки ЮKassa
   • лимиты по пользователю, выдача платного контента
   • push, админка, события аналитики
   │  только текст диалога, без идентификаторов пользователя, по секретному ключу
   ▼
LLM-шлюз — Railway (текущий server/)
   • llm.ts, systemPrompt.ts, citations.ts, knowledgeBase.ts — почти без изменений
   • ничего не хранит
   ▼
OpenRouter (deepseek/deepseek-v4-flash)
```

Изменения в шлюзе: логирование токенов, закешированных токенов и стоимости; SSE-стриминг; доступ только от ядра (CORS/ключ); лимиты по IP заменяются лимитами по пользователю в ядре.

## 3. Авторизация

- Вход обязателен, без паролей: код на email, Яндекс ID, VK ID, Telegram Login. Реализация: Better Auth + собственный обработчик Telegram.
- Аккаунты склеиваются по совпадающему email. Telegram привязывается вручную в профиле. При входе через Telegram просим email — он нужен для чеков.
- Сессии: httpOnly-cookie в вебе; для будущего нативного приложения ядро выдаёт токены.

## 4. Тарифы

| Раздел | Free | Pro |
|---|---|---|
| Тесты аккредитации | все, включая режим «как на экзамене» (80 вопросов, таймер) | + разбор ошибок от ДентИИ, слабые темы, режим «только мои ошибки» |
| Станции ОСКЭ (6 официальных) | все, со всеми вариантами ситуаций | — |
| Ситуационные задачи | — | все |
| Неотложка | всё | — |
| Коммуникация / Консультация / Приём | ~50% | всё |
| Диагностические кейсы | 5 фиксированных | все |
| Экзамен (клинические кейсы) | 1 попытка в день | без лимита |
| ИИ-Пациент | 2 архетипа | все 6 |
| ДентИИ | 3 вопроса в день | 100 в день (в интерфейсе — «безлимит», в оферте — разумное использование) |
| Прогресс | XP, стрик, счётчики | + история попыток, расширенная статистика |

- Разбор ошибок от ДентИИ расходует дневной лимит Pro.
- Закрытый контент виден с замком — это воронка.
- **Платный контент не попадает в JS-бандл**, его отдаёт ядро после проверки подписки. В бандле только бесплатный контент.
- Прогресс хранится на сервере у всех пользователей; тариф определяет только то, что показывается. Переносить локальный XP не нужно: реальных пользователей не было.

## 5. Оплата

- ЮKassa на ИП. Разовая оплата: **490 ₽ / 30 дней**, **3 990 ₽ / год**. Автопродление — позже.
- Без пробного периода. Промокоды есть с запуска (для старост и преподавателей, для беты).
- Подписка привязана к аккаунту, а не к платформе.
- Цена предварительная: финальную считаем по реальным данным (см. §8).

## 6. Контент

**Банк аккредитации.** Тесты и ситуационные задачи импортируются из открыто опубликованных материалов МЦА на fmza.ru. Право на использование подтвердил юрист. selftest.mededtech.ru не выкачиваем. Банк хранится в Postgres и **не входит в корпус ДентИИ**: около 5000 тестов — это ~300–500 тыс. токенов. Объёмы (~5000 тестов, ~380 задач) и официальный перечень станций сверяем при импорте.

**Аудитория** — выпускники специалитета. Их аккредитация: тестирование → станции ОСКЭ → ситуационные задачи.

**Объёмы на запуск:**

| Раздел | Сейчас | На запуск |
|---|---|---|
| Станции ОСКЭ | 6 | 6 + дополнительные варианты ситуаций |
| Диагностика | 17 | 30 |
| Экзамен | ~12 (лежат в `exam.tsx`, переносим в `data/`) | 25 |
| Коммуникация | 8 | 12 |

- Черновики пишет Claude (темы экзамена — на его усмотрение), вычитывает владелец вместе с врачом. Без вычитки ничего не публикуется.
- После запуска новый контент добавляется регулярно.

## 7. ДентИИ и ИИ-Пациент

- **Стриминг (SSE)** для обоих. Источники `#N` и признак `flagged` приходят в финальном событии, потому что `citations.ts` проверяет цитаты по полному тексту.
- Источники — кликабельные чипы под ответом, по нажатию открывается `/api/dentai/source/:number`.
- `flagged` — жёлтая плашка под ответом: «Источники не подтвердились — сверьтесь с протоколом».
- **Корпус ДентИИ — только справочный материал** (протоколы, процедуры, неотложка). Тренажёрные кейсы, квизы и банк аккредитации в корпус не входят. Решение проверяем на наборе из ~30 реальных вопросов: прогоняем их на полном и справочном корпусе. Если справочный отвечает хуже на вопросах о станциях, добавляем в него только чек-листы станций.
- **RAG (pgvector в той же Postgres)** — только если справочный корпус превысит ~100 тыс. токенов или кеш промпта не работает.

## 8. Экономика

Цифры ниже — замер по логам шлюза `llm_usage` 29.09.2026 на `deepseek/deepseek-v4-flash`. Цены $0.09 / $0.18 за 1M токенов (вход/выход) подтвердились. Курс условный, ~95 ₽/$.

- Вопрос к ДентИИ: ~43 тыс. входных токенов → ~$0.004 ≈ **0.40 ₽ без кеша**.
- Кеш промпта у DeepSeek срабатывает автоматически: при попадании ~37 из 43 тыс. токенов берутся из кеша, вопрос стоит ~$0.001 ≈ **0.10 ₽** (в ~4 раза дешевле).
- Попадание в кеш не гарантировано: повтор через 10 минут в кеш не попал, через 4 минуты — попал. Пока нет данных с продакшена, в расчётах закладываем цену без кеша; долю попаданий берём из логов (`cachedTokens > 0`).
- Реплика ИИ-Пациента: ~$0.0002 ≈ **0.02 ₽** (~340 входных токенов, корпус не используется).
- С подписки за 490 ₽ после эквайринга (~3.5%) и налога (6%) остаётся ~440 ₽.
- Риск — злоупотребление ДентИИ, поэтому лимиты 3 и 100 в день.

Как получить точные цифры:
1. ~~Шлюз логирует реальные токены, кеш и стоимость каждого запроса.~~ Сделано: JSON-строка `type: "llm_usage"` на каждый вызов модели.
2. Собираем постоянные расходы: Yandex Cloud, Railway, email-рассылка, домен.
3. Строим калькулятор: пользователи, конверсия, запросов на пользователя, доля кеша, курс, цена → прибыль и точка безубыточности.
4. В день запуска ставим месячный лимит расходов в OpenRouter и алерт по дневному расходу.

## 9. Уведомления (web push)

- Стрик: вечером, если за день не было активности; время выбирает пользователь (по умолчанию 19:00, по его часовому поясу).
- Новый контент.
- Подписка заканчивается: за 3 дня и в день окончания.
- Разрешение запрашиваем после первого пройденного кейса.
- На iOS push работает только в установленном PWA, поэтому нужен экран-подсказка «Установите приложение».
- Бэкенд сразу проектируем так, чтобы потом добавить нативные push через Expo.

## 10. Юридическое, админка, аналитика

- **Документы:** оферта, политика обработки ПДн, согласие на обработку. Черновики готовит Claude, проверяет юрист. Без них ЮKassa не подключит магазин.
- **Админка:** страница внутри приложения, доступ по роли admin (второй аккаунт владельца). Функции: поиск пользователя, ручная выдача и продление Pro, промокоды, расход на ИИ.
- **Аналитика:** Яндекс Метрика + события воронки в своей базе (онбординг → регистрация → первый кейс → упёрся в замок → оплата).

## 11. Домен

- Основной — **denvise.ru**, покупается у российского регистратора на ИП.
- denvise.com зарегистрирован 30.08.2026 через Namecheap. Если домен принадлежит владельцу — настраиваем переадресацию на .ru.

## 12. Возврат в сторы

- Кодовая база одна, аккаунты и подписки общие — вернуться можно в любой момент.
- Биллинг Apple и Google для российских пользователей сейчас фактически недоступен; актуальность проверить на момент выхода. Реалистичный вариант — нативное приложение без покупок внутри: вход в аккаунт, а Pro оплачивается на сайте.
- В сторы идём только после того, как веб-версия стабильно работает.

## 13. Этапы работ

1. **Расходы:** логирование токенов, кеша и стоимости в шлюзе; лимит расходов в OpenRouter.
2. **Веб-основа:** safe-area, PWA-манифест и service worker, десктопная обёртка, переходы, скелетоны.
3. **Ядро в РФ:** база, авторизация, перенос прогресса с AsyncStorage на сервер, выдача контента по API (кейсы экзамена сначала выносим в `data/`), лимиты по пользователю.
4. **Стриминг** для ДентИИ и Пациента.
5. **Банк аккредитации:** импорт с fmza.ru, режим «как на экзамене», разбор ошибок, слабые темы.
6. **Оплата:** ЮKassa, промокоды, админка, юридические документы.
7. **Push-уведомления.**
8. **Контент** до целевых объёмов; эксперимент с корпусом ДентИИ.
9. **Бета:** 10–15 друзей, бесплатный Pro по промокоду, минимум 2 недели, приёмка по критериям из §1.
10. **Калькулятор** по реальным логам → финальная цена → публичный запуск.

Жёсткого дедлайна нет: делаем как можно быстрее, но в первую очередь качественно.
